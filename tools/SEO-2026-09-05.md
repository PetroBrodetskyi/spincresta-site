# SpinCresta: crawlability improvements, 5 September 2026

## Findings

- Search Console report dated 28 August: 234 indexed URLs, 2,168 discovered but not indexed, 21 crawled but not indexed. These categories alone do not establish a ranking problem or its cause.
- A static HTML link audit found 600 sitemap pages without incoming HTML links from other sitemap pages. Country lists and casino cards were generated by JavaScript; additional cards depended on Load More.
- Known legacy URLs in the 404 report still returned 404, including `/brands/` and nested country `.html` paths.

## Implemented locally

- Real country-hub links in header HTML, preserving the interactive dropdown.
- Full country directories in the initial HTML of all ten homepages and country hubs.
- Compact expandable review-link directories on country pages, derived from existing brand-country data. Only existing indexable review URLs are included. The runtime keeps this directory visible when moving cards into the hero.
- Actual Git page modification dates in the sitemap; uncommitted HTML changes use their file modification date. Rebuilding the sitemap alone does not advance dates.
- Permanent redirects for the observed obsolete brand-directory and nested country URLs. Unknown nested paths remain 404 instead of being redirected to unrelated content.
- Repeatable crawlability audit, including reachability within each language and future-date protection.

## Verification

- All 2,410 sitemap pages reachable via HTML anchors from their own language homepage.
- SEO metadata/hreflang and site integrity audits: 2,621 HTML pages, zero errors.
- Localization structural parity: all nine translated versions passed.
- Navigation generator is idempotent (second run changes zero pages).
- Local browser: review directory opens on desktop and 390px mobile; no horizontal overflow at 390px; GoldPari link opens the correct review; Ukrainian country hub contains 64 links after JS, not a duplicated list.
- Redirect target existence, no-loop and unknown-URL checks passed locally. Actual HTTP redirects require a Vercel deployment to verify.

## Rebuild and validate

Run after changing brand availability or adding pages:

```sh
node tools/build-crawlable-navigation.mjs
node tools/generate-sitemap.mjs
node tools/audit-crawlable-navigation.mjs
node tools/verify-site-seo.mjs
node tools/audit-site-integrity.mjs
```

## After deployment

Verify live HTML and 308 redirects, then allow search engines to recrawl. Compare indexed-page counts and non-brand impressions/clicks over comparable 28-day periods. Do not interpret repeated URL submissions as a traffic strategy or promise a fixed ranking date.

The next editorial priority is verifiable, distinctive local information for the country pages already receiving impressions: evidence-backed availability, payments and bonus terms, with clear source attribution. This change does not validate every legal statement, operator claim or promotional amount across the site. Avoid manufactured reviews, ratings, keyword stuffing or mass low-quality links.
